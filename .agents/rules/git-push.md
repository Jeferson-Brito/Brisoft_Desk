# Diretriz de Git e Versionamento

- Sempre que finalizar uma tarefa, conjunto de ajustes ou correção solicitada pelo usuário:
  1. Validar integridade dos testes e compilação do projeto.
  2. Adicionar os arquivos alterados e realizar commit com mensagem semântica, clara e em português.
  3. Fazer o envio para o GitHub via `git push origin main`.
